# FeyNoBg compatibility code

The files in this directory are derived from the FeyNoBg runtime:

- Upstream: https://github.com/feyninc/nobg
- Model provider: https://huggingface.co/1038lab/FeyNobg
- License declared by the upstream source files: Apache License 2.0

The code is reduced to the BiRefNet model, image processor, and the helpers needed by the ComfyUI node. SAM3 support, model upload utilities, metrics, and unrelated utilities are not included.
